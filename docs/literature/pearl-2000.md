# Pearl, J. (2000)

- **Citation:** Pearl, J. (2000). *Causality: Models, Reasoning, and Inference*. Cambridge University Press.
- **Year:** 2000
- **Problem:** Represent and identify causal structure; distinguish seeing from doing.
- **Method:** Structural causal models, do-calculus, graphs as compact encodings of interventions.
- **Dataset/environment:** Foundational / theoretical, with running examples.
- **Objective:** Causal identification and inference, not sequential budgeted design.
- **Baseline:** Associational / purely observational statistics.
- **Limitations:** Does not by itself specify which intervention to run next under a tiny budget.
- **Relevance to ECHO:** The causal world uses a hidden SCM and hard interventions. Graph recovery is an evaluation target, not a claim that ECHO is a new identification algorithm.
- **Potential research gap:** Whether generic function-uncertainty acquisition recovers a graph as efficiently as intervention-aware design when only a few experiments are affordable.
