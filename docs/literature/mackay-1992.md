# MacKay, D. J. C. (1992)

- **Citation:** MacKay, D. J. C. (1992). Information-based objective functions for active data selection. *Neural Computation*, 4(4), 590–604.
- **Year:** 1992
- **Problem:** Where to sample next to improve a supervised model under posterior uncertainty.
- **Method:** Information-theoretic objective functions for active data selection, including variance-related criteria for Gaussian models.
- **Dataset/environment:** Illustrative regression/classification settings.
- **Objective:** Information about model parameters / predictions.
- **Baseline:** Non-adaptive or heuristic sampling.
- **Limitations:** Model-class dependent; not framed as multi-metric scientific discovery.
- **Relevance to ECHO:** Direct predecessor of local and global information-gain scores used in V0.
- **Potential research gap:** MacKay optimizes information about a model. ECHO asks whether that coincides with recovering an unknown scientific law under a small budget.
