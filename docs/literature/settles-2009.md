# Settles, B. (2009)

- **Citation:** Settles, B. (2009). *Active Learning Literature Survey*. Computer Sciences Technical Report 1648, University of Wisconsin–Madison.
- **Year:** 2009
- **Problem:** Select unlabeled points to query in order to learn a predictor with fewer labels.
- **Method:** Survey of uncertainty sampling, query-by-committee, expected model change, and related strategies.
- **Dataset/environment:** Typical supervised learning datasets in the survey's cited work.
- **Objective:** Label efficiency for prediction / classification.
- **Baseline:** Passive (random) sampling.
- **Limitations:** Scientific discovery is not the evaluation target; many methods assume i.i.d. classification/regression.
- **Relevance to ECHO:** Uncertainty sampling is Baseline 3. The survey is the standard map of active learning.
- **Potential research gap:** Active learning success on predictive error need not imply success on mechanism recovery or anomaly/hypothesis tasks.
